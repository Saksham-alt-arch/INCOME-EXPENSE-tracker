Finance App — Income & Expense Tracker
<br>
A Python GUI application that helps users track their day-to-day financial transactions and manage their money.
<br>
Track Transactions: Record daily income and expenses with dates, amounts, and descriptions.
<br>
Monthly Reports: View transactions by month and see your monthly income and expenses.
<br>
Balance Tracking: Keep track of your current balance as income and expenses are added.
<br>
Transaction History: View recent transactions and review previous financial activity.
<br>
Database Integration: Uses MySQL to store and manage financial data.
<br>
Built With
<br>
Python • PyQt5 • MySQL • SQL • Git
